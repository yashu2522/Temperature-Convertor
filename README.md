# Temperature Converter 🌡️

A simple web application that converts temperatures between Celsius and Fahrenheit.

This project was built as part of revising JavaScript fundamentals, focusing on user input handling, conditional logic, and DOM manipulation.

## 🚀 Tech Stack

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## ✨ Features

* Convert temperature from Fahrenheit to Celsius
* Convert temperature from Celsius to Fahrenheit
* User input validation for correct values
* Displays results with formatted output (2 decimal places)
* Simple and clean UI

## 📚 What I Practiced

* Handling user input and validation
* Using conditional logic (`if-else`)
* DOM manipulation with `getElementById`
* Type conversion using `parseFloat()`
* Formatting output using `toFixed()`

## 📌 Future Improvements

* Add real-time conversion (on input change)
* Improve UI with better styling and layout
* Add Kelvin conversion
* Include unit toggle buttons instead of dropdown

## 📁 Project Status

Completed as a revision project to strengthen JavaScript fundamentals and real-world calculations.
